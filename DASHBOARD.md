# 🏠 Домашняя страница (Dashboard)

## 📍 Доступ

Откройте в браузере: **http://localhost:3000/dashboard**

## 🎯 Функциональность

### Аутентификация
- Вход / Регистрация прямо на странице
- Сохранение токена в localStorage
- Отображение текущего пользователя

### 🎯 Раздел "Тренажеры"

Содержит 12 тренажеров с красивыми иконками:

1. **📚 Словарь** - угадывание перевода
2. **✏️ Подстановка** - вставить пропущенное слово
3. **🌐 Перевод** - перевод греческой фразы
4. **🔊 Аудио** - слушание и угадывание
5. **📍 Ударения** - выбор правильного ударения
6. **❌ Ошибки** - найти ошибку в слове
7. **🎴 Карточки** - флешкарточки
8. **✍️ Письмо** - написание по памяти
9. **🔥 МИКС** - случайные упражнения
10. **⚡ Спряжение** - спряжение глаголов
11. **🎯 Неправильные глаголы** - учить исключения
12. **🔗 1-е спряжение** - регулярные глаголы

Каждый тренажер открывается в основной интерфейс (index.html)

### 📚 Раздел "Словари"

#### Все слова
Кнопка для просмотра полного списка всех слов в БД

#### По категориям (Системные)
Автоматически загруженные категории:
- **📦 Существительные** (существ.)
- **⚡ Глаголы** (гл.)
- **👤 Местоимения** (м.)
- **🎨 Прилагательные** (прил.)
- **⏩ Наречия** (нар.)
- **🔗 Предлоги** (предл.)

#### Мои категории (Пользовательские)
- Создавайте собственные категории для группировки слов
- Каждая категория имеет:
  - Название (текст)
  - Иконку (эмодзи)
- После создания категория появляется в разделе "Мои категории"

## 🔧 API Endpoints

### Categories API

```bash
# Получить системные категории
GET /api/categories/system

# Получить категории пользователя (требует авторизации)
GET /api/categories/user
Authorization: Bearer <token>

# Создать категорию (требует авторизация)
POST /api/categories/user
Authorization: Bearer <token>
Content-Type: application/json
{
  "name": "Еда",
  "icon": "🍽️"
}

# Получить слова категории
GET /api/categories/:categoryId/words

# Удалить категорию (требует авторизация)
DELETE /api/categories/user/:id
Authorization: Bearer <token>
```

## 💾 База данных

Добавлены новые таблицы:

### word_categories
```sql
id          INTEGER PRIMARY KEY
name        TEXT NOT NULL UNIQUE
icon        TEXT
is_system   BOOLEAN (1 = системные, 0 = пользовательские)
created_at  TIMESTAMP
```

### user_word_categories
```sql
id          INTEGER PRIMARY KEY
user_id     INTEGER (связь с users)
name        TEXT NOT NULL
icon        TEXT
created_at  TIMESTAMP
```

### words (обновлена)
```sql
category_id INTEGER (связь с word_categories)
-- остальные поля без изменений
```

1. Откройте dashboard
